## Problem Description
Managing daily schedules can be challenging, especially when unexpected changes arise. Many people struggle to balance work, personal commitments, and urgent tasks efficiently. Current scheduling tools lack the intelligence to dynamically adjust tasks based on urgency and flexibility.

## Objective
To develop an AI-powered scheduler that plans and reschedules tasks intelligently. The system will adapt to user preferences using machine learning and provide a dynamic, personalized scheduling experience.

## Key Features
- **Dynamic Task Rescheduling**: Adjusts schedule based on urgency/flexibility.
- **Task Suggestions**: Recommends tasks you might have missed.
- **Priority Management**: Users can assign importance levels.
- **Personalized Scheduling**: Learns user preferences.
- **Conflict Detection**: Avoids double-booking and overlaps.

## Dataset
We will use a public scheduling dataset from Kaggle to train and test task prediction and prioritization logic.
